# Sparktro Admin using Laravel + Vue 3 + Inertia.js Starter

This is a starter project integrating Laravel backend with Vue 3 frontend using Inertia.js for seamless SPA-like navigation.

---

## Prerequisites

- PHP >= 8.1
- Composer
- Node.js >= 16.x and npm/yarn
- A database (MySQL/PostgreSQL/SQLite)
- Laravel CLI (optional but recommended)
